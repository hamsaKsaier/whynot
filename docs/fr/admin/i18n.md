# Internationalisation de l'interface d'administration

## Arbre de décision des espaces de noms

L'interface d'administration utilise 5 espaces de noms i18n. Choisissez le bon :

| Espace de noms | Quand l'utiliser | Exemples de clés |
|-----------|------------|--------------|
| `common` | Actions partagées, pagination, libellés de statut, notifications | `admin.common.save`, `admin.status.active` |
| `auth` | Connexion admin, expiration de session | `auth.login.title` |
| `admin` | Clés spécifiques par page d'administration | `admin.audit.*`, `admin.featureFlags.*` |
| `settings` | Paramètres système, configuration de facturation | `settings.title`, `settings.tabs.*` |
| `superadmin` | Fonctionnalités réservées aux super-admins (plans, crédits) | `plans.*`, `credits.*` |

## Ajouter une nouvelle clé

1. Ajoutez la clé anglaise au fichier d'espace de noms approprié dans `admin-frontend/public/locales/en/<namespace>.json`.
2. Ajoutez les traductions aux 4 autres langues : `ar`, `fr`, `de`, `es`.
3. Utilisez la clé dans votre composant : `const { t } = useTranslation('<namespace>')` puis `t('key.path')`.
4. Exécutez `make test-admin` pour vérifier que le test `i18n-completeness` passe.

### Format des cles

- `admin.json` utilise des **cles plates** : `"admin.audit.title": "Journal d'audit"`
- `common.json`, `superadmin.json`, `auth.json`, `settings.json` utilisent des **cles imbriquees** : `{ "admin": { "status": { "active": "Actif" } } }`

## Localisation des devises

Les valeurs monétaires sont stockées en cents (bigint) dans le backend. Affichez-les avec `Intl.NumberFormat`.

## Localisation des dates

Les dates respectent la langue i18n active. L'attribut `dir` est défini sur `<html>` pour le RTL quand l'arabe est actif.

## Chaînes d'événements du journal d'audit

Les chaînes de types d'événements du journal d'audit sont stockées dans le backend. L'interface admin localise les libellés de filtres via les clés `admin.audit.actionLabels.*`.

Pour la localisation des messages backend, voir `/docs/fr/i18n.md`.

## Règles de qualité de traduction

| Langue | Règle |
|----------|------|
| Français | Espace insécable (NBSP `\u00A0`) avant `: ; ! ?` |
| Espagnol | Paires de ponctuation inversée : `¿...?` et `¡...!` |
| Allemand | Doit contenir des marqueurs allemands (ä, ö, ü, ß) |
| Toutes | La syntaxe `{{placeholder}}` doit être préservée exactement |
