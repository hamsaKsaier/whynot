# Internationalisierung des Admin-Frontends

## Entscheidungsbaum für Namespaces

Das Admin-Frontend verwendet 5 i18n-Namespaces. Wählen Sie den richtigen:

| Namespace | Wann verwenden | Beispielschlüssel |
|-----------|------------|--------------|
| `common` | Gemeinsame Aktionen, Paginierung, Statusbezeichnungen, Benachrichtigungen | `admin.common.save`, `admin.status.active` |
| `auth` | Admin-Anmeldung, Sitzungsablauf | `auth.login.title` |
| `admin` | Feature-spezifische Schlüssel pro Admin-Seite | `admin.audit.*`, `admin.featureFlags.*` |
| `settings` | Systemeinstellungen, Abrechnungskonfiguration | `settings.title`, `settings.tabs.*` |
| `superadmin` | Nur Super-Admin-Funktionen (Pläne, Guthaben) | `plans.*`, `credits.*` |

## Einen neuen Schlüssel hinzufügen

1. Fügen Sie den englischen Schlüssel zur entsprechenden Namespace-Datei in `admin-frontend/public/locales/en/<namespace>.json` hinzu.
2. Fügen Sie Übersetzungen für alle 4 anderen Sprachen hinzu: `ar`, `fr`, `de`, `es`.
3. Verwenden Sie den Schlüssel in Ihrer Komponente: `const { t } = useTranslation('<namespace>')` dann `t('key.path')`.
4. Führen Sie `make test-admin` aus, um den `i18n-completeness`-Test zu überprüfen.

### Schlüsselformat

- `admin.json` verwendet **flache Schlüssel**: `"admin.audit.title": "Audit Log"`
- `common.json`, `superadmin.json`, `auth.json`, `settings.json` verwenden **verschachtelte Schlüssel**: `{ "admin": { "status": { "active": "Active" } } }`

## Währungslokalisierung

Geldwerte werden als BigInt-Cents im Backend gespeichert. Anzeige mit `Intl.NumberFormat`.

## Datumslokalisierung

Daten berücksichtigen die aktive i18n-Sprache. Das `dir`-Attribut wird auf `<html>` für RTL-Layout gesetzt, wenn Arabisch aktiv ist.

## Audit-Log-Ereigniszeichenfolgen

Audit-Log-Ereignistyp-Zeichenfolgen werden im Backend gespeichert. Die Admin-Oberfläche lokalisiert Filterbeschriftungen über `admin.audit.actionLabels.*`-Schlüssel.

Für die Backend-Nachrichtenlokalisierung siehe `/docs/de/i18n.md`.

## Übersetzungsqualitätsregeln

| Sprache | Regel |
|----------|------|
| Französisch | Geschütztes Leerzeichen (NBSP `\u00A0`) vor `: ; ! ?` |
| Spanisch | Invertierte Satzzeichenpaare: `¿...?` und `¡...!` |
| Deutsch | Muss deutsche Marker enthalten (ä, ö, ü, ß) |
| Alle | `{{placeholder}}`-Syntax muss sprachübergreifend exakt beibehalten werden |
