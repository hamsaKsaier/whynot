# Changelog

## 2026-04-24 — Recon ist da: Pentest bei jedem Release

Recon ist ab sofort verfügbar. Recon führt einen autorisierten, autonomen Sicherheitsscan gegen Ihre Anwendung durch und meldet ausschließlich bestätigte Exploits — jeder Befund enthält einen reproduzierbaren Proof-of-Concept, den Sie direkt an Engineering oder Security weitergeben können.

Wir haben Recon gebaut, weil die meisten Scanner Sie mit unbestätigten Signalen überfluten. Recon dreht den Ablauf um: Es crawlt das Ziel, führt aktive Prüfungen durch und bestätigt jede Kandidaten-Schwachstelle, bevor sie im Report erscheint. Kein Exploit, kein Report. Das bedeutet weniger Rauschen, schnelleres Triage und Befunde, auf die Ihr Team noch am selben Tag reagieren kann.

Recon wird diese Woche hinter einem Feature-Flag für bestehende Workspaces ausgerollt. Sobald es für Sie aktiviert ist, sehen Sie einen einmaligen Hinweis in der App und den Recon-Eintrag in Ihrer Seitenleiste.
