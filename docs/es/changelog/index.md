# Registro de cambios

## 2026-04-24 — Llega Recon: un pentest en cada release

Recon ya está disponible. Recon ejecuta un escaneo de seguridad autorizado y autónomo contra tu aplicación y solo reporta exploits comprobados — cada hallazgo incluye una prueba de concepto reproducible que puedes entregar a los equipos de ingeniería o seguridad.

Construimos Recon porque la mayoría de los escáneres inundan al usuario con señales sin verificar. Recon invierte el flujo: rastrea el objetivo, ejecuta sondas activas y confirma cada vulnerabilidad candidata antes de que aparezca en el reporte. Sin exploit, no hay reporte. Esto significa menos ruido, triaje más rápido y hallazgos accionables el mismo día.

Recon se está desplegando detrás de un feature flag para los workspaces existentes esta semana. Cuando esté habilitado para ti, verás un aviso único dentro de la app y la entrada Recon en tu barra lateral.
