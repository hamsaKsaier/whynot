# Internacionalización del Frontend de Administración

## Árbol de decisión de espacios de nombres

El frontend de administración utiliza 5 espacios de nombres i18n. Elija el correcto:

| Espacio de nombres | Cuándo usar | Claves de ejemplo |
|-----------|------------|--------------|
| `common` | Acciones compartidas, paginación, etiquetas de estado, notificaciones | `admin.common.save`, `admin.status.active` |
| `auth` | Inicio de sesión de admin, expiración de sesión | `auth.login.title` |
| `admin` | Claves específicas por página de administración | `admin.audit.*`, `admin.featureFlags.*` |
| `settings` | Configuración del sistema, configuración de facturación | `settings.title`, `settings.tabs.*` |
| `superadmin` | Funciones solo para super administradores (planes, créditos) | `plans.*`, `credits.*` |

## Agregar una nueva clave

1. Agregue la clave en inglés al archivo de espacio de nombres apropiado en `admin-frontend/public/locales/en/<namespace>.json`.
2. Agregue traducciones a los 4 idiomas restantes: `ar`, `fr`, `de`, `es`.
3. Use la clave en su componente: `const { t } = useTranslation('<namespace>')` luego `t('key.path')`.
4. Ejecute `make test-admin` para verificar que la prueba `i18n-completeness` pase.

### Formato de clave

- `admin.json` usa **claves planas**: `"admin.audit.title": "Registro de auditoría"`
- `common.json`, `superadmin.json`, `auth.json`, `settings.json` usan **claves anidadas**: `{ "admin": { "status": { "active": "Activo" } } }`

## Localización de moneda

Los valores monetarios se almacenan como bigint en centavos en el backend. Muéstrelos usando:

```typescript
const formatted = new Intl.NumberFormat(i18n.language, {
  style: 'currency',
  currency: currencyCode, // e.g. 'usd'
}).format(Number(cents) / 100);
```

Nunca muestre directamente `String(cents / 100)`.

## Localización de fechas

Las fechas respetan el idioma i18n activo. El atributo `dir` se establece en `<html>` para el diseño RTL cuando el árabe está activo.

## Cadenas de eventos del registro de auditoría

Las cadenas de tipos de eventos del registro de auditoría se almacenan en el backend. La interfaz de admin localiza las etiquetas de filtros mediante claves `admin.audit.actionLabels.*`.

Para la localización de mensajes del backend, consulte `/docs/es/i18n.md`.

## Reglas de calidad de traducción

| Idioma | Regla |
|----------|------|
| Francés | Espacio de no separación (NBSP `\u00A0`) antes de `: ; ! ?` |
| Español | Pares de puntuación invertida: `¿...?` y `¡...!` |
| Alemán | Debe contener marcadores alemanes (ä, ö, ü, ß) |
| Todos | La sintaxis `{{placeholder}}` debe preservarse exactamente en todos los idiomas |
