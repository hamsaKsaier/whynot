## 1. الملخص

النتيجة الحرجة هي حقن SQL في نقطة نهاية `/api/v1/orders` يسمح لمهاجم غير مصادَق عليه بقراءة صفوف عشوائية من جدولَي `orders` و`customers`. **عاملها كحادثة.**

## 3. النتائج (مقتطف)

### النتيجة 1 — حقن SQL في `/api/v1/orders`

| الحقل | القيمة |
|-------|--------|
| **الخطورة** | حرِجة |
| **الفئة** | حقن SQL (CWE-89) |
| **الهدف** | `GET /api/v1/orders?status=<param>` |
| **الثقة** | عالية |
| **نتيجة الاستغلال** | قراءة مؤكَّدة |

**ما الذي حدث.** يُسلسل معامل الاستعلام `status` على `/api/v1/orders` في عبارة `WHERE` لـ SQL دون معاملة. يمكن للمهاجم الكسر من سياق السلسلة وحقن SQL عشوائي. لا تتطلب مصادقة.

**إثبات المفهوم.**

```http
GET /api/v1/orders?status=open'%20UNION%20SELECT%20[REDACTED]%20--%20 HTTP/1.1
Host: example-staging.acme.dev

HTTP/1.1 200 OK
Content-Type: application/json

{"orders":[{"id":1,"status":"[REDACTED-RESPONSE]"}]}
```

أعادت عبارة `UNION` المحقونة بيانات من جدول مختلف، مؤكِّدةً الحقن. الحمولة الفعلية والاستجابة محرَّرتان في هذا النموذج.

**لماذا هذا مهم.** يمكن لمهاجم غير مصادَق عليه قراءة كل صف في أي جدول لمستخدم قاعدة البيانات وصول إليه، شاملًا جدولَي `customers` و`orders`. هذه أعلى فئة ثغرات تأثيرًا ضد قاعدة بيانات تطبيق ويب نموذجي.

**المعالجة الموصى بها.** استبدل تسلسل السلاسل باستعلامات معاملاتية في معالج `/api/v1/orders` بأكمله. مسار الشفرة نفسه موجود على الأرجح في نقاط نهاية مجاورة — دقّق الملف. انظر OWASP A03:2021 — Injection للإرشاد العام.

**مراجع.**

- CWE-89: تحييد غير سليم للعناصر الخاصة المستخدمة في أمر SQL.
- OWASP Top 10 2021: A03 — Injection.

### النتيجة 2 — تحكم وصول مكسور على `/admin/users`

| الحقل | القيمة |
|-------|--------|
| **الخطورة** | عالية |
| **الفئة** | تحكم وصول مكسور (CWE-285) |
| **الهدف** | `GET /admin/users/{id}` |
| **الثقة** | عالية |
| **نتيجة الاستغلال** | قراءة مؤكَّدة |

**ما الذي حدث.** تتحقق نقطة نهاية `/admin/users/{id}` من أن مُقدِّم الطلب مُسجَّل دخول لكنها لا تتحقق من امتلاكه دور `admin`. أي مستخدم مصادَق يمكنه قراءة ملف أي مستخدم آخر، بما في ذلك البريد الإلكتروني والدور.

**إثبات المفهوم.** أعاد طلب مصادَق قياسي من حساب غير مسؤول الملف الكامل لمستخدم آخر. الطلب والاستجابة محرَّران.

**المعالجة الموصى بها.** أضف فحص دور إلى معالج المسار. دقّق كل نقاط نهاية `/admin/*` بحثًا عن الفجوة نفسها.

### النتيجة 3 — XSS مخزَّن في ملاحظات الطلب

| الحقل | القيمة |
|-------|--------|
| **الخطورة** | عالية |
| **الفئة** | XSS مخزَّن (CWE-79) |
| **الهدف** | `POST /api/v1/orders/{id}/notes` |
| **الثقة** | عالية |
| **نتيجة الاستغلال** | قراءة مؤكَّدة |

**ما الذي حدث.** يُخزَّن حقل `notes` على طلب دون تطهير ويُعرض كـ HTML على صفحة تفاصيل الطلب. يمكن لمستخدم منخفض الصلاحية حقن سكربت ينفَّذ عند عرض المسؤول للطلب.

**إثبات المفهوم.** خُزّنت حمولة `<script>` (محرَّرة) ولوحظ تنفيذها في جلسة منفصلة.

**المعالجة الموصى بها.** اعرض `notes` كنص، لا كـ HTML. إن كان النص الغني مطلوبًا، فاستخدم مُطهّرًا موثقًا بقائمة سماح صارمة.

## 5. فجوات التغطية

- **مسارات إدارية مصادَق عليها.** أُعطي ريكون حساب اختبار منخفض الصلاحية لكن لم يُعطَ حساب مسؤول. النتائج على `/admin/*` محدودة بالمشاكل التي يمكن لمصادَق غير مسؤول الوصول إليها.
- **تقييد معدل WAF.** أعادت ثلاث نقاط نهاية تحت `/api/v1/billing/*` `429 Too Many Requests` بعد 12 فحصًا لكل منها. تجاوز الزحف المعامِلات المتبقية في تلك النقاط.
- **مهام الخلفية.** لا يُمارس ريكون قوائم انتظار المهام غير المتزامنة أو المهام المجدوَلة. المشكلات التي تظهر فقط في معالجة الخلفية خارج النطاق.
