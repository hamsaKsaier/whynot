# تدويل واجهة الإدارة

## شجرة قرار مساحات الأسماء

تستخدم واجهة الإدارة 5 مساحات أسماء i18n. اختر المناسب:

| مساحة الاسم | متى تُستخدم | أمثلة على المفاتيح |
|-----------|------------|--------------|
| `common` | الإجراءات المشتركة، التصفح، حالات الحالة، الإشعارات | `admin.common.save`، `admin.status.active` |
| `auth` | تسجيل دخول الإدارة، انتهاء الجلسة | `auth.login.title` |
| `admin` | مفاتيح خاصة بكل صفحة إدارية | `admin.audit.*`، `admin.featureFlags.*` |
| `settings` | إعدادات النظام، إعداد الفوترة | `settings.title`، `settings.tabs.*` |
| `superadmin` | ميزات المسؤول الأعلى فقط (الخطط، الأرصدة) | `plans.*`، `credits.*` |

## إضافة مفتاح جديد

1. أضف المفتاح الإنجليزي إلى ملف مساحة الاسم المناسب في `admin-frontend/public/locales/en/<namespace>.json`.
2. أضف الترجمات إلى اللغات الأربع الأخرى: `ar`، `fr`، `de`، `es`.
3. استخدم المفتاح في المكون: `const { t } = useTranslation('<namespace>')` ثم `t('key.path')`.
4. شغّل `make test-admin` للتحقق من اجتياز اختبار `i18n-completeness`.

### صيغة المفاتيح

- `admin.json` يستخدم **مفاتيح مسطحة**: `"admin.audit.title": "Audit Log"`
- `common.json`، `superadmin.json`، `auth.json`، `settings.json` يستخدمون **مفاتيح متداخلة**: `{ "admin": { "status": { "active": "Active" } } }`

## توطين العملات

تُخزّن القيم النقدية كأعداد صحيحة كبيرة (سنتات) في الخلفية. اعرضها باستخدام `Intl.NumberFormat`.

## توطين التواريخ

تحترم التواريخ لغة i18n النشطة. يُضبط اتجاه `dir` على `<html>` لتخطيط RTL عند تفعيل العربية.

## سلاسل أحداث سجل التدقيق

تُخزّن سلاسل أنواع أحداث سجل التدقيق في الخلفية. تقوم واجهة الإدارة بتوطين تسميات الفلاتر عبر مفاتيح `admin.audit.actionLabels.*`.

لتوطين رسائل الخلفية، راجع `/docs/ar/i18n.md`.

## قواعد جودة الترجمة

| اللغة | القاعدة |
|----------|------|
| الفرنسية | مسافة غير منقطعة (NBSP) قبل `: ; ! ?` |
| الإسبانية | أزواج علامات الترقيم المقلوبة: `¿...?` و `¡...!` |
| الألمانية | يجب أن تحتوي على علامات ألمانية (ä، ö، ü، ß) |
| الكل | يجب الحفاظ على صيغة `{{placeholder}}` بالضبط عبر اللغات |
