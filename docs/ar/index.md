## دعم RTL

تدعم الواجهة بالكامل اتجاه الكتابة من اليمين إلى اليسار للغة العربية. عند اختيار العربية:

- يتم تعيين `dir="rtl"` على عنصر HTML
- تُعكس تخطيطات Flexbox تلقائيًا
- تُستخدم خصائص CSS المنطقية (`ms-*`، `me-*`، `ps-*`، `pe-*`)
- تُعكس الأيقونات الاتجاهية باستخدام `rtl:scale-x-[-1]`
