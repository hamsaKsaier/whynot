# تكوين الذكاء الاصطناعي للمستخدم

يشرح هذا الدليل كيفية عمل إعدادات مزود الذكاء الاصطناعي من منظور المستخدم، بما في ذلك مستويات الاشتراك وإدارة المفاتيح والرجوع إلى مفاتيح المنصة.

## مستويات الاشتراك

يقدم WhyNot QA مستويين من الاشتراك يحددان كيفية الوصول إلى مزودي الذكاء الاصطناعي:

### أحضر مفاتيحك الخاصة (`byo_keys`)

الخطط: **مجاني**، **احترافي (مفاتيح خاصة)**

- يجب على المستخدمين تقديم مفاتيح API الخاصة بهم لاستخدام ميزات الذكاء الاصطناعي
- لا يوجد وصول إلى المفاتيح المُدارة من المنصة
- يقوم المستخدمون بتكوين المزودين في **الإعدادات ← الذكاء الاصطناعي**
- يتم تشفير المفاتيح باستخدام AES-256-GCM

### مُدار + الدفع حسب الاستخدام (`managed_payg`)

الخطط: **احترافي (مُدار + الدفع حسب الاستخدام)**

- توفر المنصة مفاتيح ذكاء اصطناعي مُعدة مسبقاً — لا حاجة لأي إعداد
- يتم تحصيل الرسوم من المستخدمين حسب الاستخدام
- يمكن للمستخدمين اختيارياً إضافة مفاتيحهم الخاصة
- عندما يكون لدى المستخدم مفتاح خاص، فإنه يأخذ الأولوية على مفاتيح المنصة

## كيف يعمل اختيار المزود

1. يتحقق النظام أولاً مما إذا كان لدى المستخدم مفتاح API شخصي مُكوّن
2. إذا وُجد مفتاح شخصي وتم تعيينه كافتراضي، يتم استخدامه
3. إذا لم يكن هناك مفتاح شخصي وكان المستخدم على خطة `managed_payg`، يتم استخدام المزود الافتراضي للمنصة
4. إذا لم يكن هناك مفتاح شخصي وكان المستخدم على خطة `byo_keys`، فإن ميزات الذكاء الاصطناعي غير متاحة

## المزودون المُكوّنون من قبل المسؤول

يتم التحكم في قائمة المزودين المتاحة من قبل مسؤول المنصة في **المسؤول ← مزودو الذكاء الاصطناعي**. تظهر فقط المزودين الذين قام المسؤول بتفعيلهم في القائمة المنسدلة للمستخدم.

خيار `مخصص (متوافق مع OpenAI)` متاح دائماً.

## علامة تبويب الإعدادات (`الإعدادات ← الذكاء الاصطناعي`)

### لمستخدمي `byo_keys`

- يوضح شعار أن مفاتيح API مطلوبة
- إذا لم يتم تكوين مفاتيح، يظهر تنبيه لإضافة واحد

### لمستخدمي `managed_payg`

- يشير شعار إلى أن الوصول المُدار للذكاء الاصطناعي مُتضمن في الخطة
- إذا لم يتم تكوين مفاتيح شخصية، تظهر رسالة بالمزود الافتراضي الحالي للمنصة

### إضافة مفتاح مزود

1. انقر على **إضافة مزود**
2. اختر مزوداً من القائمة المنسدلة
3. اختر نموذجاً
4. للمزود "المخصص"، أدخل عنوان URL الأساسي
5. أدخل مفتاح API
6. انقر على **حفظ**

### إدارة المفاتيح

- **اختبار الاتصال**: يتحقق من عمل مفتاح API عبر إرسال طلب اختبار
- **تعيين كافتراضي**: يجعل هذا المزود الافتراضي لعمليات الذكاء الاصطناعي
- **حذف**: يزيل تكوين المزود

## الاحتياط لمفاتيح المنصة

بالنسبة لمستخدمي `managed_payg`، تحتفظ المنصة بسلسلة احتياط من مزوّدي الذكاء الاصطناعي يُكوّنها المسؤول. إذا فشل المزوّد الأساسي، يحاول النظام تلقائيًا المزوّد التالي في ترتيب الاحتياط.

يتم تكوين ترتيب الاحتياط والمزوّد الافتراضي في **المسؤول ← مزودو الذكاء الاصطناعي ← إعدادات الفوترة الافتراضية**.
