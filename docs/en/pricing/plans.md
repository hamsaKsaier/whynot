# Pricing Plans

WhyNot offers three plans designed for different stages of growth.

## Free

**$0/month** — no credit card required.

Best for individuals and personal projects exploring autonomous QA.

| Feature | Included |
|---------|----------|
| Test runs per month | 50 |
| Projects | Up to 3 |
| AI bug detection | Yes |
| Playwright code generation | Yes |
| Support | Community |

## Pro (BYO Keys)

**$29/month** (or $23/month billed annually — save 20%).

For teams who want unlimited testing power using their own AI provider API keys (OpenAI, Anthropic, etc.).

| Feature | Included |
|---------|----------|
| Test runs | Unlimited |
| Projects | Unlimited |
| Bring your own API keys | Yes |
| Visual regression testing | Yes |
| Chaos testing | Yes |
| CI/CD integration | Yes |
| Support | Priority |

A 14-day free trial is included — no credit card required to start.

## Pro (Managed)

**$49/month** (or $39/month billed annually — save 20%).

Full power with platform-managed AI infrastructure and pay-as-you-go credits.

| Feature | Included |
|---------|----------|
| Everything in Pro BYO | Yes |
| Managed AI infrastructure | Yes |
| Pay-as-you-go credits | Yes |
| Advanced analytics | Yes |
| Custom monitors | Yes |
| SSO & team management | Yes |
| Support | Dedicated |

## Choosing the right plan

- **Just exploring?** Start with Free — upgrade anytime.
- **Have your own LLM keys?** Pro BYO gives you unlimited runs at a fixed monthly cost.
- **Want zero setup?** Pro Managed handles AI infrastructure for you; you only pay for credits you use on top of the base subscription.

## Billing

- Monthly and annual billing available.
- Annual billing saves 20% compared to monthly.
- All prices in USD.
- Cancel anytime — no long-term contracts.
