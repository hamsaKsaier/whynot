# Admin Frontend Internationalization

## Namespace Decision Tree

The admin-frontend uses 5 i18n namespaces. Choose the right one:

| Namespace | When to use | Example keys |
|-----------|------------|--------------|
| `common` | Shared actions, pagination, status labels, toasts | `admin.common.save`, `admin.status.active` |
| `auth` | Admin login, session expiry | `auth.login.title` |
| `admin` | Feature-scoped keys per admin page | `admin.audit.*`, `admin.featureFlags.*` |
| `settings` | System settings, billing config | `settings.title`, `settings.tabs.*` |
| `superadmin` | Super admin-only features (plans, credits) | `plans.*`, `credits.*` |

## Adding a New Key

1. Add the English key to the appropriate namespace file in `admin-frontend/public/locales/en/<namespace>.json`.
2. Add translations to all 4 other languages: `ar`, `fr`, `de`, `es` in their respective files.
3. Use the key in your component: `const { t } = useTranslation('<namespace>')` then `t('key.path')`.
4. Run `make test-admin` to verify the `i18n-completeness` test passes (ensures key parity across languages).

### Key format

- `admin.json` uses **flat keys**: `"admin.audit.title": "Audit Log"`
- `common.json`, `superadmin.json`, `auth.json`, `settings.json` use **nested keys**: `{ "admin": { "status": { "active": "Active" } } }`

## Currency Localization

Monetary values are stored as bigint cents in the backend. Display them using:

```typescript
const formatted = new Intl.NumberFormat(i18n.language, {
  style: 'currency',
  currency: currencyCode, // e.g. 'usd'
}).format(Number(cents) / 100);
```

Never display raw `String(cents / 100)`.

## Date Localization

Dates honor the active i18n language:

```typescript
Intl.DateTimeFormat(i18n.language, { dateStyle: 'medium' }).format(new Date(iso))
```

The `dir` attribute is set on `<html>` for RTL layout when Arabic is active.

## Audit Log Event Strings

Audit log *event type* strings (e.g. `user.role_change`) are stored in the backend. The admin UI localizes:
- **Filter labels**: via `admin.audit.actionLabels.*` keys in `admin.json`
- **Display**: The raw action string is shown in badges; localized labels appear in filter dropdowns

For backend message localization, see `/docs/en/i18n.md`.

## Translation Quality Rules

| Language | Rule |
|----------|------|
| French | Non-breaking space (NBSP `\u00A0`) before `: ; ! ?` |
| Spanish | Inverted punctuation pairs: `¿...?` and `¡...!` |
| German | Must contain German markers (ä, ö, ü, ß, or common German words) |
| All | `{{placeholder}}` syntax must be preserved exactly across languages |
