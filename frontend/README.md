# Thunder Code Frontend

Modern React + Vite frontend for the Thunder Code POC.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- ✅ Test input form with validation
- ✅ Test case generation visualization
- ✅ Real-time test execution monitoring
- ✅ Test results display with statistics
- ✅ Screenshot gallery with lightbox
- ✅ Responsive design
- ✅ Modern UI with Tailwind CSS

## Environment Variables

Create a `.env` file:

```
VITE_API_URL=http://localhost:3000/api
```

## Usage

1. Enter website URL and user story
2. Click "Generate Tests" to see test cases
3. Click "Run Test" to execute tests
4. View results and screenshots
